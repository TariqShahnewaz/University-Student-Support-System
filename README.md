
# University Student Support System

**A simple web platform that helps university students report campus issues and enables administrators to manage and resolve them efficiently.**

The **University Student Support System** is a web-based application designed to improve communication between students and university authorities. Students can report campus-related problems, monitor the progress of their reports, and stay informed about issues affecting their university. Administrators can review submissions, update their status, and maintain an organized record of reported problems.

# Overview

Managing campus-related issues can be challenging when students have no dedicated platform for reporting problems. Many concerns, such as damaged classrooms, network failures, maintenance requests, or cleanliness issues, are communicated through informal channels, making them difficult to track and manage.

The University Student Support System provides a centralized platform where students can submit reports and administrators can monitor, update, and resolve them through an organized workflow.

---

# Problem Statement

Many universities still rely on verbal communication, social media groups, or personal messages for reporting campus problems. This creates several challenges:

- Reports can easily be overlooked.
- Students cannot monitor the progress of submitted issues.
- Administrators have difficulty organizing multiple reports.
- Duplicate complaints are common.
- Communication between students and administration is inefficient.

A centralized reporting system can simplify this process by keeping all reports in one secure and organized platform.

---

# Project Objectives

The project aims to:

- Build a centralized platform for reporting campus-related issues.
- Improve communication between students and university administration.
- Allow students to monitor the progress of submitted reports.
- Help administrators manage reports efficiently.
- Provide a clean, simple, and user-friendly interface.
- Maintain organized records of reported campus problems.

# Database Overview

The application stores its data in a MySQL database.

Main tables include:

### Users

Stores student and administrator information.

### Universities

Stores available university information.

### Reports

Stores submitted campus issues including:

- Report Title
- Category
- Location
- Description
- Suggested Solution
- Status
- Date Submitted
- Admin Comment
